# best-apis

Ready-to-run data APIs on [Apify](https://apify.com/best_apis), plus open-source examples and tools for using them.

## Actors

| Actor | What it does |
|---|---|
| [**ATS Jobs Feed**](https://apify.com/best_apis/ats-jobs-feed) | Daily-refreshed index of open jobs from 12,000+ company career sites (Greenhouse, Lever, Ashby, SmartRecruiters, Recruitee, Personio): search, daily changes and company hiring signals |
| [**App Store & Google Play Reviews Scraper**](https://apify.com/best_apis/app-store-play-reviews) | App reviews from both stores as clean JSON |
| [**Walmart Scraper**](https://apify.com/best_apis/walmart-product-price-scraper) | Products, prices, stock and a built-in price tracker |
| [**Federal Register API**](https://apify.com/best_apis/federal-register-api) | US rules, proposed rules and notices as JSON |
| [**Steam Reviews Scraper**](https://apify.com/best_apis/steam-reviews-scraper) | Public Steam game reviews and app details |

## Open-source repos

| Repo | Description |
|---|---|
| [ats-jobs-feed-examples](https://github.com/best-apis/ats-jobs-feed-examples) | Python examples: job search, daily alerts, hiring signals, salary stats |
| [ats-jobs-mcp](https://github.com/best-apis/ats-jobs-mcp) | MCP server that gives AI agents job search, new-job and hiring-signal tools |
| [app-reviews-examples](https://github.com/best-apis/app-reviews-examples) | App Store and Google Play reviews to CSV, low-rating alerts |
| [walmart-price-tracker-examples](https://github.com/best-apis/walmart-price-tracker-examples) | Walmart price-drop alerts and search to CSV |
| [federal-register-monitor-examples](https://github.com/best-apis/federal-register-monitor-examples) | Federal Register digests and RSS feeds |
| [steam-reviews-analysis-examples](https://github.com/best-apis/steam-reviews-analysis-examples) | Steam review sentiment and negative-review exports |

Examples are MIT licensed. Free sample data and a jobs data report: https://best-apis.pages.dev
